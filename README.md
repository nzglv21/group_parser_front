# Панель администратора «Попутчики» (group_parser_admin)

Современная панель управления для сервиса парсинга и агрегации попутчиков `group_parser`, разработанная на **React 18 + TypeScript + Ant Design (AntD) + Vite**.

## Возможности

- 📊 **Дашборд & Мониторинг**:
  - Live статус PostgreSQL (latency ms), Telegram Telethon парсера, VK воркера и VK бота.
  - KPI метрики: пользователи (TG/VK, DAU, WAU), поисковые запросы, активные поездки, подписки.
  - Интерактивные графики динамики регистраций (14 дней), почасовой активности поисков (0-23ч), статусов поездок.
  - Сравнение спроса и предложения: Топ-10 направлений пассажиров vs Топ-10 маршрутов водителей.
- 🚗 **Поездки (Trips)**:
  - Фильтрация по статусам (`active`, `full`, `completed`), платформам (`Telegram`, `ВКонтакте`), городам и датам.
  - Просмотр промежуточных остановок с временем прибытия, исходного текста объявления, авто и контактов.
  - Прямые ссылки на исходные посты в Telegram и VK.
  - Удаление поездок с подтверждением.
- 📡 **Источники парсинга (Sources)**:
  - Реестр групп/каналов с переключателем активности on/off в один клик.
  - **Быстрое добавление по ссылке**: автоматическое определение платформы, ID группы и названия по URL (`/sources/by-url`).
  - Ручное добавление и редактирование источников.
  - Удаление источников.
- 👥 **Водители & Лидеры (Drivers)**:
  - Сводная аналитика: общее число водителей, активные за 30 дней, топ-платформа.
  - Зал славы (Топ-5 лидеров по поездкам).
  - Поиск водителей по марке авто, контактам, ID.
  - Выдвижная панель (Drawer) с полной историей поездок и маршрутов выбранного водителя.
- 🧭 **Матрица расстояний (Distances)**:
  - Таблица времени в пути между городами для расчета ETA остановок.
  - Фильтр и предупреждения для ненастроенных маршрутов (0 минут).
  - Создание новых пар городов и редактирование времени в пути.
- 👤 **Пользователи (Users)**:
  - Список пользователей Telegram/VK, количество поисков и подписок, дата регистрации и активность.
- 🔍 **Логи поисков (Searches)**:
  - Журнал живых поисков пассажиров с фильтрами по успешности выдачи (>0 или 0 поездок) и платформам.
- ⚙️ **Настройки & Авторизация**:
  - Поддержка HTTP Basic Auth (по умолчанию `nzglv` / `nzglv`).
  - Переключение адреса бэкенда (localhost или продакшн).
  - Инструмент моментальной диагностики подключения к API и БД.
  - Светлая / Темная тема Ant Design.

## Запуск в разработке

```bash
# Установка зависимостей (если не установлены)
npm install

# Запуск локального dev-сервера с проксированием к FastAPI (порт 8000)
npm run dev
```

Dev-сервер запустится на [http://localhost:3000](http://localhost:3000).

## Сборка для продакшна

```bash
npm run build
```

Собранные статические файлы будут находиться в папке `dist/`. Их можно раздавать через Nginx, Caddy, FastAPI static files или любой веб-сервер.
